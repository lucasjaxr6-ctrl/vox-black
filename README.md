# VOX · Dashboard do lojista (demonstração)

Demonstração navegável do novo dashboard do lojista VOX, com dados fictícios.

**Abrir:** https://lucasjaxr6-ctrl.github.io/vox-black/

- **Antes / Depois:** compara o dashboard original com o novo layout.
- **Desktop / Celular:** mostra o painel na tela do computador ou num celular de 390 px.
- O filtro de período, os cartões que filtram os gráficos e os visitantes ao vivo funcionam; os números são gerados no navegador, sem servidor.

Esta branch (`main`) guarda só o site publicado. O código-fonte da demonstração fica na branch `fonte`.
